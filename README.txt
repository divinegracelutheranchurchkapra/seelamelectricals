SEELAM ELECTRICALS — UPDATED RESPONSIVE WEBSITE

Pages
- index.html — Home page with a 3-slide hero carousel, brand strip, product categories and contact calls to action.
- about.html — Company background and commitments.
- products.html — Product categories, cable catalogues, DWC pipe details and live product search.
- brands-industries.html — Brand directory with linked brand marks and official website links.
- industries.html — Dedicated industry directory with enquiry paths for each sector.
- contact.html — Phone, email, WhatsApp and enquiry form.
- style.css — Shared styling across all pages.
- assets/ — Supplied logo, flyers, brochures and catalogue images.

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder in VS Code or your file manager.
3. Double-click index.html to open it in Chrome or Edge.
4. Use the same navigation and product search on every page.

FUNCTIONALITY
- The homepage carousel changes slides automatically and supports previous/next buttons and slide dots.
- The shared product search sends the search term to Products; the product finder filters the catalogue cards live.
- Phone links use tel: links; WhatsApp buttons open a WhatsApp enquiry.
- Product enquiry links can prefill the contact form. The contact form prepares an email using the visitor's email application. It does not send information to a server.
- The site is static. Publish it to a hosting provider to make it publicly accessible.
